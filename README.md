# Chandru portfolio

A responsive, self-contained static portfolio site with an editorial, cinematic direction inspired by the reference you shared. The site includes a custom 3D-inspired hero illustration, a work index, editable case-study pages, About, Services, Process, and Contact sections, plus a light/dark theme toggle.

## Open the site

Open `index.html` in a browser. Project cards open the shared case-study template in `work.html`.

## Personalize it

Open `script.js` and edit the `S` object at the top. It contains your name, email, availability, work cards, services, and process steps. Replace every bracketed placeholder with your own project information, images, links, and availability before publishing. No client names, results, testimonials, or credentials have been invented.

The project cover artwork is built from CSS shapes as visual stand-ins. Replace those with your own project images when you are ready. The hero illustration is inline SVG; it can be replaced with a render or a 3D scene.

## Publish

Upload the complete `outputs` folder to a static web host such as GitHub Pages, Netlify, or Vercel. The site has no build step or package dependencies. Google Fonts are loaded from Google Fonts when a network connection is available; local serif and sans-serif fallbacks are included.
